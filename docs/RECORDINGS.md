# 录音配置与长短文件播放（3.6）

本包包含全部74个用户MP3文件，位于 `audio/001.mp3` 等。只统一文件名，音频字节保持原样。原文件名、时长、SHA-256、用途与未绑定原因见 `config/audio_manifest.json` / `docs/AUDIO_INVENTORY.md`；标签依据文件名整理，未逐句听写。所有文件都是单声道，70个16000Hz、4个24000Hz，时长1.680～62.100秒。

## 配置与目录

- `config/audioplay.json`：程序唯一运行配置，audio/policy/voices在启动时解析一次。
- `config/audio_manifest.json`：完整素材清单，不参与调度，也不会根据其中的duration_seconds决定播放结束。
- `audio/编号.mp3`：原始录音；40个已绑定、2个可替换、32个待绑定，均可保留在此目录。

构建demo自动复制到 `build/bin/config` 和 `build/bin/audio`；cmake install同步安装。ROS片段在节点重新链接后复制到节点旁边，catkin install同样部署；只编辑源配置而不重新链接节点时，需把更新后的配置复制到实际节点的config目录。运行时路径根据真实可执行文件定位，与启动时工作目录无关。

运行配置示例（voices中的部分条目）：

```json
{
  "manual_mode": {
    "file": "../audio/003.mp3",
    "text": "手动模式已开启。"
  },
  "automatic_mode": {
    "file": "../audio/004.mp3",
    "text": "自动模式已开启。"
  },
  "fault:device/9/*": {
    "file": "../audio/069.mp3"
  }
}
```

相对路径以JSON所在目录为基准。默认自动模式用004；032包含“要立刻运行请按启动按钮”，仅作为替代素材，不额外推断该控制条件。109是当前脱轨提示，可按需要将对应file替换为045。

设备先查精确资源 `fault:device/9/65535`，再查 `fault:device/9/*`，再查fault；任一条目命中后file/text一起生效。未配置text则使用当前错误内置文案。录音不含具体码时仍保留错误ID和码用于排序、去重及TTS。

文件可用就播放完整文件内容；缺失、无法解码或读取失败时尝试TTS。输出设备故障和已取消任务不回退TTS。修改JSON后重启；替换既有路径上的MP3，下次播放任务即可读取新文件，不需要改代码或转成WAV。

## 文件长短与重复

引擎分块读取/解码并输出，等最后的输出缓冲播放完成才返回Completed。不需要给每条录音配置时长。前后静音、文件内部的重复段落都属于文件内容，不自动裁剪。

| 场景 | 正常结束与重播 | 提前结束 |
| --- | --- | --- |
| 手动/自动模式 | 003约1.8秒、004约1.68秒；整条完成后清除事件，相同模式不重复 | 更高优先级、新模式、无效模式输入或退出；仍有效且未完成的模式被抢占后从头重播 |
| 持续故障、急停、充电、低电、运动 | 完整文件完成后间隔repeat_interval_ms（默认1秒），再按最新状态决定是否重播 | 优先级/场景变化或解除；充电/运动也受输入超时影响 |
| 障碍 | 累计被选中30秒，包括句间隔；被高优先级覆盖时暂停累计 | 到时取消当前文件，继续无声占位，障碍解除后释放 |

例如061为8.1秒，默认约9.1秒启动下一次；043为59.076秒，默认约60.076秒启动下一次。不会按一秒定时叠加播放。

**005障碍录音50.076秒大于默认30秒窗口，持续障碍时会在文件结束前取消。** 本次保持已确认的MCU累计窗口。若后续要求完整播放005，需要明确调整policy.obstacle_limit_ms或更改“窗口结束等整句完成”的业务规则，两者含义不同；本包未擅自选择。

## 已接入的状态范围

模式、运动、横移、障碍、低电、充电、急停、通用/IPC/设备故障均从现有AudioState取得。横移使用已有vx/vy：abs(vy)≥linear_enter且abs(vx)≤linear_exit进入，abs(vy)≤linear_exit或abs(vx)≥linear_enter退出；转弯条件优先，双向都有明显速度时用运行提示。

充电结束不等于充满；动作失败不等于动作超时；通用触边不包含MCU touch_err的车体/托盘细分；State没有这些信息就不自动触发相关录音。所有待绑定条目和IPC录音编号差异详见AUDIO_INVENTORY.md、FAULT_MAPPING.md。

MP3和原有PCM WAV可混用；引擎仍按内容解码，volume作用于两者，speed只影响TTS。本次74个MP3均通过实际mpg123解码、完整输出到模拟后端的检查；未进行扬声器试听或逐句听写。
